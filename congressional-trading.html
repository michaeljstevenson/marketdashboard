Methodology

Universe is the full S&P 500. For every constituent, Alpha Vantage's CONGRESS_TRADES endpoint returns each stock-trading disclosure filed by a member of the US House or Senate under the STOCK Act (2012) — the same public-record legal category as the Form 4 filings behind Insider Buying/Selling, just a different filer population and disclosure regime. Only transactions dated within the trailing 12 months as of the last refresh are counted.

Every dollar figure on this page is an estimate, not an exact reported amount. The STOCK Act requires disclosure of trade size only as a bracketed range (e.g. "$1,001-$15,000"), never an exact dollar figure — a hard limit of the source data, not something this page can improve on. Every dollar figure shown — net flow, sector totals, leaderboards, the regression's x-axis — uses the midpoint of each trade's disclosed range as its estimate.

The window is 12 months, not the 90 days used by Insider Buying/Selling: the STOCK Act allows a member up to 45 days to disclose a trade after making it, and per-company congressional trading volume is much lower than corporate Form 4 activity, so a shorter window risks too few disclosures per company for meaningful sector aggregates. Even at 12 months, a "recent" window can still be systematically missing the newest transactions still inside their up-to-45-day notification window — a real trade from the last month and a half may not show up here yet.

Two real data-quality findings shaped this page's filtering, found by inspecting live responses rather than assumed from a single example: (1) the disclosed asset-type code is not consistently ST — recent House filings use that code for common stock, but Senate filings report the same common-stock trades as Stock instead, so this page accepts both (case-insensitively) rather than the stricter single-code filter that would silently drop every Senate trade; a distinct Stock Option code, genuinely not common stock, is excluded. (2) the disclosure's own "filing status" field is populated on House filings but consistently blank on every Senate filing, so it can't be used to separate real transactions from placeholder records — the real signal is transaction type: rows are kept only when marked BUY or SELL, excluding a real third category (OTHER) that represents account-transfer/subholding disclosures rather than a discretionary trade.

Party (D/R) is a genuine, disclosed field in this data, and it's shown here — the trades-by-party cross-tab above and the party-split column in the full table below — the same way any other cross-tab on this site is shown: as one neutral, descriptive data cut, never framed as commentary, endorsement, or criticism of any individual or party.

Cluster buying mirrors Insider Buying/Selling's own screen exactly: 2+ distinct members of Congress buying with zero members selling the same name in the window — the least ambiguous signal this kind of disclosure data can offer, since it isn't explainable by one filer's idiosyncratic personal-finance reasons alone.

The forward-return regression tests the literal question this dataset invites — does disclosed congressional trading activity predict subsequent relative price performance, the subject of academic work such as Ziobrowski et al. (2004, 2011) on both House and Senate disclosures. Rather than regressing the raw dollar net flow, which would be dominated by whichever handful of companies happen to attract the largest few individual disclosures (a small number of high-net-worth members can dwarf everyone else's disclosed amounts), this page uses a normalized net-flow ratio — estimated buy $ minus estimated sell $, divided by estimated buy $ plus estimated sell $, in a range of -1 to +1 — restricted to companies with at least 2 qualifying trades in the window so the ratio isn't just an artifact of a single disclosure. It reuses this same cycle's Relative Strength Leaders/Laggards 3-month price return relative to SPY, the same cross-page pattern Buyback Dollar-Value Tracker, Institutional Ownership & Flow Tracker, and News Sentiment Momentum use, rather than running a second full-universe price sweep. If that data hasn't refreshed yet this cycle, this page still shows every other chart and table — sector flow, cluster buying, all three leaderboards, the party cross-tab, the full company table — just without the regression, and a banner above says so.

Sector and company name come from the same weekly metadata sweep that backs Sector Beeswarm, reused here rather than paying for a second full-index pass just for labels. Only the derived aggregate fields described above are retained per company — the full per-trade disclosure list (which can run to hundreds of rows for a heavily-traded name) is not stored past the run that computes these aggregates. As of September 2026 this and most other full-sweep pages on this site refresh as one-time snapshots (run manually from the Netlify dashboard) rather than on a recurring schedule, to control Alpha Vantage call volume — see this page's own scheduled background function for the current status.
