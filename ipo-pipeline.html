Methodology

What this tracks. Alpha Vantage's IPO_CALENDAR endpoint returns the current IPO filing calendar — symbol, company name, scheduled IPO date, price range (if set), currency, and exchange — for roughly the next three months. It's a genuinely thin dataset at any given moment; a single-digit number of new rows on a given pull is normal, not a bug. This page pulls it weekly (Saturday), classifies every row, and folds it into two views: the current calendar (what's scheduled to list soon) and an accumulating aftermarket roster (what has actually listed since this page went live, and how it's traded since).

Operating company vs. fund/trust. A meaningful share of what shows up in a raw IPO calendar isn't an operating business going public at all — it's a new closed-end fund, unit investment trust, or SPAC-style acquisition vehicle. Each row is tagged by a case-insensitive substring match against the company name for the patterns: trust, fund, etf, closed-end, depositor, index fund, acquisition corp(oration), acquisition co(mpany), and spac. This list is deliberately not exhaustive — it mirrors the same real-world data-quality cleanup this site's SPLITS-endpoint background job already needed for a different Alpha Vantage calendar-style feed — and only the "operating" rows feed the aftermarket-tracking roster below; funds/trusts still show in the raw calendar table for transparency but aren't tracked further.

Why no historical backfill. A natural first instinct for an "IPO aftermarket performance" page is to join a list of past IPOs against their price history going back years. That was investigated and ruled out: Jay Ritter's dataset (the historical annual source behind IPO Activity) is aggregate year-level statistics only — average first-day return, count, proceeds — with no individual-ticker list to join against price data. IPO_CALENDAR itself is forward-looking only, showing roughly the next three months and nothing further back, so it can't retroactively fill that gap either. Rather than fabricate or approximate a backfill, this page instead builds an honest, forward-accumulating track record: every operating-company IPO this page has ever seen on a calendar pull gets added to a roster, and once its IPO date actually passes, its own price history is tracked going forward. The roster (and the pipeline-size trend chart above) will only get more useful as more weeks accumulate — an early, short history is exactly that, a start, not a full cycle.

Day-1/5/10/20 returns vs. SPY. For each roster entry, the "anchor day" is the first trading day at or after its IPO date. The anchor price is that day's open (there's no reliable pre-listing "offer price" trade data in daily bars, so the first print's open stands in for it). Day-N return is the cumulative move from the anchor day's open to the close N trading days later (Day 1 = the anchor day's own close). SPY's return is computed the same way, over the exact same calendar window — anchor-day open to the close on the same target date — and the relative return shown is simply stock return minus SPY return at that horizon. A horizon is left blank until enough trading days have actually elapsed; once Day 20 is filled in, that entry is marked complete and isn't re-fetched. If a name's IPO date passes and Alpha Vantage returns no price series for it at all for three straight weekly runs (or 45 calendar days go by with never a print), it's marked abandoned rather than tracked forever — some filed IPOs get pulled or delayed indefinitely.

Floor, not forecast. The five-year Ritter counts above are shown purely as background context for what a "normal" year's IPO pace looks like — they are not compared or annualized against the current ~3-month forward calendar, and that comparison would be misleading if drawn: IPO_CALENDAR only shows filings that already have a scheduled date, so the true forward pipeline at any moment is always larger than what currently has a set date on the calendar. Treat the current-calendar counts above as a floor on near-term activity, never as an implied full-year run rate.
