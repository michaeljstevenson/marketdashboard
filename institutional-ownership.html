Methodology

Universe is the full S&P 500. For every constituent, Alpha Vantage's INSTITUTIONAL_HOLDINGS endpoint reports current 13F-derived institutional ownership as a set of top-level aggregates: total institutional holders, total institutional shares, the number of holders (and shares) that increased, decreased, or held unchanged since the prior reporting period, and total institutional ownership as a % of shares outstanding. The same response also carries a full per-holder holdings array — for a widely-held mega-cap this can run to thousands of rows and 1MB+ of JSON — which this page deliberately does not retain: only the top-level aggregate fields are parsed out of each response, and the holdings array is discarded immediately rather than stored, since retaining it across ~503 companies would bloat storage for no analytical benefit this page needs.

Institutional ownership % is total_institutional_ownership_percentage, parsed directly. Net institutional flow % — this page's core "accumulation vs. distribution" signal — is shares held by increasing holders minus shares held by decreasing holders, divided by total institutional shares: positive means more institutional buying pressure than selling pressure showed up in this reporting period, negative the reverse. Net holder count change is the simpler, holder-count-based companion signal — holders increased minus holders decreased — it can diverge from the share-weighted flow % (e.g. many small holders trimming a position while one large holder adds heavily, or vice versa), which is why both are shown side by side rather than collapsed into one number. A company is excluded entirely, not fabricated, if total_institutional_shares is zero, missing, or unparseable (the flow % denominator can't be computed) or if the top-level aggregate fields are literally absent from the response (no usable 13F coverage for that symbol this run).

The ownership/flow leaderboards apply a floor of 50 reporting institutional holders — every S&P 500 constituent is a multi-billion-dollar company that should clear this comfortably in the overwhelming majority of cases, but a name with only a handful of 13F filers can otherwise show a wildly noisy ownership % or net flow % off one or two holders moving, which isn't a meaningful "most/least" signal for a S&P 500-wide leaderboard. That floor applies to the four leaderboards only — the full company table below includes every loaded constituent regardless of holder count.

INSTITUTIONAL_HOLDINGS is a current-state snapshot with no history endpoint of its own — the same category as OVERVIEW behind Forward vs. Trailing P/E Divergence or EARNINGS_ESTIMATES behind Analyst Estimate Dispersion — so the market-wide weekly median ownership % and median net flow % are appended to a running history each run rather than fabricated as a synthetic time series. That trend line starts thin the week this page ships and only becomes meaningful after several weeks of real runs accumulate; the chart says so honestly rather than implying a one- or two-point line means anything.

The forward-return test reuses this same cycle's Relative Strength Leaders/Laggards 3-month price return relative to SPY, the same cross-page pattern Buyback Dollar-Value Tracker and Earnings Growth vs. Price Performance use, rather than running a second full-universe price sweep. If that data hasn't refreshed yet this cycle, this page still shows every other chart and table — ownership by sector, the flow distribution, the trend, all four leaderboards, the full company table — just without the regression, and a banner above says so.

Sector and company name come from the same weekly metadata sweep that backs Sector Beeswarm, reused here rather than paying for a second full-index pass just for labels. As of September 2026 this and most other fundamentals-sweep pages on this site refresh as one-time snapshots (run manually from the Netlify dashboard) rather than on a recurring schedule, to control Alpha Vantage call volume — see this page's own scheduled background function for the current status.
