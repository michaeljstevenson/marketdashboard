Methodology

Universe is the full S&P 500. For every constituent, Alpha Vantage's INSTITUTIONAL_HOLDINGS endpoint returns a set of top-level summary fields alongside a per-institution holder list (Vanguard, BlackRock, and so on — thousands of rows for a mega-cap). This page reads only the summary fields — total_institutional_holders, total_institutional_shares, total_institutional_ownership_percentage, the holders_with_increased_holdings / holders_with_decreased_holdings / holders_with_unchanged_holdings counts, and the corresponding shares_with_* counts — and never fetches, stores, or processes the underlying holder-by-holder list. This page is about aggregate institutional positioning across the index, not tracking individual 13F filers, and parsing thousands of holder rows per company across a ~503-company sweep would add real cost for no benefit to what's shown here.

Two different questions, both answered on this page. Total institutional ownership % is a level — what share of shares outstanding institutions currently hold, as of the latest reporting period. Net accumulation breadth is a flow/breadth measure, computed per company as:

net accumulation breadth = (holders increased − holders decreased) ÷ total institutional holders × 100

A positive score means more institutions added to their position than trimmed it this reporting period; negative means more trimmed than added. The two measures are deliberately kept separate because they can point opposite directions: a stock can carry very high institutional ownership that's completely flat or even net-distributing (a mature, widely-held name nobody's actively rotating into or out of), while a newer or smaller name can show a strongly positive breadth score off a much lower ownership base. This is the same structural idea as Earnings Revisions' "Net Revision Ratio" — a breadth ratio of how many entities are moving in each direction, not a magnitude — applied here to institutional holder counts instead of analyst estimates.

A company is skipped entirely if total_institutional_holders is missing or zero (there's no meaningful ratio to compute against a zero denominator) or if Sector Beeswarm's own weekly metadata sweep has no sector for it — company name, sector, and market cap are reused from that page's OVERVIEW-derived meta.json rather than paying for a second full-index sweep just for labels, the same pattern several other pages on this site use. Separately, total_institutional_ownership_percentage is excluded — for that one field only, not the whole row — if it comes back above 100%: true institutional ownership can't exceed shares outstanding, and a reading past that bound is a known data-vendor double-count artifact (share-class/ETF look-through quirks in aggregated 13F data), not a real positioning signal. A company failing only that check still keeps its net accumulation breadth score, since that figure is computed from a separate set of fields and isn't affected by the ownership-% issue.

The history chart is a genuine accumulating time series, not a single snapshot: INSTITUTIONAL_HOLDINGS only reports each company's own current-period summary, not a market-wide series, so each weekly run appends that week's cross-company median net accumulation breadth to a running series rather than replacing it — the same pattern Earnings Revisions, P/E Divergence, and Free Cash Flow Yield use for their own trend lines. It starts thin the week this page ships and becomes more informative with every subsequent run.

The scatter tests whether net accumulation breadth predicts subsequent relative price performance: x is each company's net accumulation breadth this run, y is Relative Strength Leaders/Laggards' own 3-month return relative to SPY, reused read-only from that page's latest snapshot rather than running a second ~503-call price sweep — the same cross-page idiom Earnings Growth vs. Price Performance Divergence already uses against the same blob. This is deliberately "this week's positioning vs. a separate forward/contemporaneous return snapshot," not "this week's rank vs. next week's rank" — two overlapping return windows measured a week apart would share almost all of their underlying trading days and correlate mechanically regardless of any real signal, the same overlapping-window pitfall Relative Strength Leaders/Laggards' own methodology avoids. If Relative Strength Leaders/Laggards' snapshot isn't populated yet, this page still shows every other chart and table normally — the scatter and its regression are simply empty until that page's own job has run at least once. Both cross-page dependencies (Sector Beeswarm and Relative Strength Leaders/Laggards) are themselves periodic snapshots, not continuously live feeds, so a company newly missing from either can briefly widen coverage gaps between them.

The regression uses the same Pearson and Spearman two-method check used throughout Factor Analysis and this site's other regression checks. A weak or noisy relationship is itself informative here — it would say institutional flow, at least at this weekly-snapshot cadence, doesn't mechanically lead near-term relative price performance.

Refreshes on manual runs for now (see this job's own netlify.toml comment) — institutional ownership is reported off 13F filings, which update quarterly at most, so nothing here needs a daily or even a strict weekly cadence to stay current.

Source: Alpha Vantage — INSTITUTIONAL_HOLDINGS (summary fields only), plus company name/sector/market cap via Sector Beeswarm's OVERVIEW-derived metadata and 3-month relative return via Relative Strength Leaders/Laggards' own snapshot
