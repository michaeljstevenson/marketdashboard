Methodology

Universe is the full S&P 500. For every constituent, Alpha Vantage's OVERVIEW endpoint returns 52WeekHigh and 52WeekLow — a single-endpoint sweep (~503 calls), the same shape/cost as R&D Intensity and RSI Mean-Reversion Screen. Current price for each company (needed to place it within its own 52-week range) is read from Relative Strength Leaders/Laggards' own weekly price history rather than a second price sweep — the same reuse this page's forward-return test also depends on (below). Range position is (price − 52WeekLow) / (52WeekHigh − 52WeekLow), expressed as a percentage from 0% (at the 52-week low) to 100% (at the 52-week high), clipped to that band on the rare occasion a live price sits fractionally outside a slightly-stale high/low reading (Alpha Vantage refreshes 52WeekHigh/52WeekLow "generally the same day a company reports its latest earnings," not necessarily same-day as the price snapshot this page joins against).

Every constituent is ranked by range position each run and split into 10 equal-count deciles (decile 1 = lowest range position / nearest the 52-week low, decile 10 = highest range position / nearest the 52-week high). Sector and company name come from the same weekly metadata sweep that backs Sector Beeswarm.

This page tests the 52-week high effect (George & Hwang, 2004) — the well-documented tendency for stocks trading near their 52-week high to keep outperforming, rather than mean-revert — the opposite-signed cousin of RSI Mean-Reversion Screen's short-term-reversal test on this same site. Because the current-price join is itself a current-state snapshot, the test needs successive weekly runs: each week's range-position decile per company is recorded, then joined against that company's own realized return — relative to SPY, using the same compounding excess-return construction as Relative Strength Leaders/Laggards — from that snapshot to the next weekly snapshot. Company and SPY prices for that join are read directly from Relative Strength Leaders/Laggards' own weekly price history (it already keeps one point per week for its own rank-persistence test) rather than paying for a second full-index price sweep; a week is skipped from the test, not recorded as a fabricated zero-return week, if that source data hasn't advanced since this page's prior run.

The core result is a decile-bucket bar chart of average next-week relative return, plus a pooled Pearson-and-Spearman regression (same two-method check as Factor Analysis) of range position against forward relative return across every accumulated pair. A positive, statistically significant slope is consistent with the 52-week-high effect: today's near-high names continuing to outperform next week, today's near-low names continuing to underperform. This needs at least two weekly snapshots before a single forward-return pair exists at all, and several more before a per-decile average is anything but noise — the page shows a plain "not enough history yet" message rather than a chart or regression built on too little data.

Weekly recurring job (Saturday) — unlike most fundamentals sweeps added to this site since mid-September 2026 (one-time snapshots re-run manually), this one has to keep running: the momentum test only exists because successive weekly range-position snapshots can be compared to each other.
