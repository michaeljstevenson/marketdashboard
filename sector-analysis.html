How to read this

Each column is a different lookback window ending on the most recent trading day: 1D is today's close vs. yesterday's; 1W is roughly five trading days back; MTD/QTD/YTD compare today's close to the last close of the prior month, quarter, and calendar year respectively (the standard "since period-start" convention used on most market data terminals); and 1M/3M/6M/1Y are rolling trailing returns measured from today back a fixed number of calendar months, regardless of month/quarter/year boundaries. 1Y and YTD are not the same thing — 1Y is a rolling trailing year, YTD resets every January 1st.

Absolute shows each sector's own price return. Relative to S&P 500 shows each sector's return minus SPY's return over the same window — positive means that sector outperformed the broad market over that period, negative means it lagged, regardless of whether the market itself was up or down. This is the more useful view for spotting sector rotation: a sector can post a negative absolute return while still being relatively strong (losing less than the market), or a positive absolute return while relatively weak (gaining less than the market).

Sectors are the 11 SPDR Select Sector ETFs (XLK, XLF, XLV, XLE, XLI, XLY, XLP, XLU, XLB, XLRE, XLC), which together track the entire S&P 500 by GICS sector. Returns are price returns only (dividends excluded), computed from daily closing prices.
