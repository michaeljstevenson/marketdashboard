This page aggregates those scores into a per-call tone — split between the scripted prepared remarks and the unscripted Q&A — and tests whether that tone actually tracks how good the quarter's numbers were, or runs on its own.

Methodology

Universe is the full S&P 500. For each constituent, this snapshot pulls Alpha Vantage's EARNINGS endpoint for the latest reported quarter's EPS surprise, then pulls EARNINGS_CALL_TRANSCRIPT for that quarter's call. Alpha Vantage itself runs an LLM sentiment score (−1 to +1) on every individual statement in the transcript — this page doesn't compute sentiment itself, it aggregates the scores Alpha Vantage already provides. Every statement from Alpha Vantage's own "Operator" role is dropped before averaging (procedural, not informative); everything else is classified as either an analyst statement (title contains "Analyst") or a management statement (everything else — CEO, CFO, IR, and any other company-side speaker). This is a simple heuristic, not an exhaustive title taxonomy, in the same spirit as this site's other name/title-pattern classifiers (e.g. the fund/trust filter behind IPO Pipeline).

"Prepared remarks" is everything before the first analyst statement in the transcript; "Q&A" is everything from that point on. Overall sentiment averages every non-operator statement. Prepared sentiment and Q&A sentiment average only management statements in each section. Tone gap is Q&A sentiment minus prepared sentiment — a negative gap means management sounds less upbeat once questions start, a positive gap means the opposite. Analyst sentiment (shown in the per-company table's underlying data but not charted separately) is the average tone of the questions themselves.

The two regression tests are cross-sectional, one point per company, using this run's own EPS surprise % (reported EPS vs. consensus estimate, same EARNINGS field and the same divide-by-near-zero and blow-up filters Earnings Surprise History uses) against (1) overall call sentiment and (2) the tone gap — Pearson and Spearman, matching the two-method check used throughout Factor Analysis. Both ask a version of the same question: does the way a call sounds actually track how good the quarter's numbers were, or is management's tone mostly decoupled from the print?

The trickiest part of building this page: Alpha Vantage's transcript quarter parameter (e.g. "2024Q1") is labeled by each company's own fiscal quarter, not the calendar quarter — confirmed by direct testing during development, Apple's fiscal year starts in October, so its "2024Q1" transcript covers Oct–Dec 2023, while a calendar-year reporter's "2024Q1" covers Jan–Mar 2024. Neither endpoint states a company's fiscal-year-start month, so this run makes one calendar-quarter guess per company (correct for the roughly four-fifths of the index that reports on a calendar year) and does not retry companies where that guess misses — Apple, Microsoft, and other off-calendar-fiscal-year reporters are likely under-represented or absent from this particular snapshot as a result. A future refresh could add per-company calibration; see this job's own code comments for the bounded search that would require.

One-time snapshot, not a recurring pull (matches this site's current policy for its most recently added Equities pages) — companies report on their own schedule, so unlike a page built around one shared "latest quarter," this one's per-company quarters span whatever window each company's own most recent call falls into (shown above as the analyzed date range). A fresh run can be triggered manually from the Netlify dashboard.
